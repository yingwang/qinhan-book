# 秦汉那些事儿：帝国初生的四百年

> 一部用现代大白话拆解中华第一帝国兴衰的长篇历史叙事。从公元前 259 年邯郸小巷里那个随时会被拉去祭旗的秦国“肉票”，一直讲到公元 220 年许昌受禅台上交出玉玺的末代天子——四百余年间，一套延续两千年的国家骨架如何铸就，一群有血有肉的帝王将相与贩夫走卒如何在时代巨浪里博弈、挣扎与发光。

---

## 这本书怎么写历史

读秦汉史，最怕两种极端：一种是板着脸背诵年代与制度名词，把活生生的人变成教科书上的木头雕像；另一种是脱离史料瞎编戏说，堆砌廉价段子。

这本书试图走第三条路：

*   **硬核史料打底，现代白话拆解**：以《史记》《汉书》《后汉书》《资治通鉴》及秦汉简牍研究为骨架，官制、地理、战役推演与财政账本严丝合缝，但统统翻译成现代人一听就懂的人情世故与利益算计。
*   **把历史人物还原成“活人”**：写嬴政的孤独与控制欲，写刘邦的无赖与豁达，写项羽的骄傲与幼稚，写韩信的天真与委屈，写王莽的偏执与荒诞，也写刘秀的温和与深沉。
*   **故事外壳之下，算清底层账本**：在刀光剑影之外，用算账的方式讲透——为什么郡县制能赢分封制？为什么汉武帝打赢了匈奴却差点把国库打崩？为什么东汉从建国第一天起就埋下了豪强割据与外戚宦官死循环的雷？
*   **留住穿越两千年的温情**：权谋终会成灰，真正撑起民族脊梁的，是张骞在荒漠里攥紧十三年的汉节、司马迁在暗室里忍辱写下的竹简、班超三十六人横绝西域的孤胆，以及范滂临刑前对母亲的告别。
