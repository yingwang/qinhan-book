# 全书总纲与人物志

## 一、 叙事准则

1. **硬核史料打底，现代白话拆解**：以《史记》《汉书》《后汉书》《资治通鉴》及秦汉简牍研究成果为骨架，时间、官制、地理、战役逻辑、财政账本严丝合缝；把文言文里的微言大义还原成现代人一听就懂的职场博弈、利益算计与生死抉择。
2. **克制的冷幽默，拒绝廉价烂梗**：不堆砌过时的浮夸段子，而用**反差感、冷峻的大实话与精准的短句转折**制造阅读快感。
3. **把历史人物还原成“活人”**：帝王将相不是教科书上的木头雕像。写透他们在历史十字路口的犹豫、恐惧、虚荣、算计与孤勇。
4. **讲透制度与财政底层逻辑**：用算账的方式讲明白郡县制与分封制的优劣、盐铁官营的代价、豪强庄园的坐大，以及外戚与宦官为何陷入死循环。
5. **笑中带泪的历史温情**：嬉笑怒骂之后，留住中国历史最动人的底色——个体在命运洪流中的尊严与坚守。

- **时代跨度**：公元前 259 年（嬴政生于邯郸）/ 公元前 221 年（大秦一统）—— 公元 220 年（曹丕代汉，东汉落幕），纵贯 **440 余年**中华第一帝国完整周期。
- **全书规模**：共 **六卷 · 二十四章**（全书完结），纯汉字约 **24 万字**（含标点约 **28.5 万字符**）。

  - 汉成帝与赵飞燕、赵合德姐妹的温柔乡绝境，汉哀帝与董贤“断袖之癖”闹剧。
  - 超长待机太皇太后王政君撑起的外戚王氏帝国，直到那个最谦卑孝顺的侄子走到舞台中央。

#### [第15章：穿越者王莽的魔幻乌托邦](15-wangmang-utopia.md)

#### [第16章：庄稼汉刘秀与昆阳神迹](16-liuxiu-kunyang.md)

  - 长兄刘縯被更始帝猜忌诛杀后，刘秀单骑谢罪、饮食言笑如常，深夜独自咬破嘴唇泪湿枕席的顶级隐忍。

#### [第17章：云台将星与柔道治国](17-yuntai-roudao.md)

  - 东汉最大的基因缺陷——“度田”妥协：面对豪强地主武装对抗选择退让，世家豪族庄园与经学门阀自此坐大。

#### [第18章：明章之治与班超孤悬绝域](18-mingzhang-banchao.md)
