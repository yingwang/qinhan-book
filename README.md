# 秦汉那些事儿：帝国初生的四百年

> 一部用现代白话拆解中华第一帝国兴衰的长篇历史书。从公元前 259 年赵国邯郸小巷里的秦国质子，讲到公元 220 年许昌受禅台上的末代汉帝——纵贯四百四十余年，还原硬核史料背后的人性博弈、制度逻辑与家国悲欢。

**在线阅读**：[yingwang.github.io/qinhan-book](https://yingwang.github.io/qinhan-book/)

---

## 全书规划（六卷 · 二十四章）

*   **第一卷：铁血大秦（前 259 — 前 207）**：超级帝国的狂飙、沙丘惊变与大泽乡烽火（第 1–3 章）
*   **第二卷：楚汉惊雷（前 207 — 前 195）**：鸿门宴、暗度陈仓、韩信封神与霸王别姬（第 4–6 章）
*   **第三卷：文景韬晦（前 195 — 前 141）**：吕后铁腕、文帝治国智慧与七国之乱（第 7–8 章）
*   **第四卷：汉武铁骑（前 141 — 前 48）**：卫霍封狼居胥、张骞凿空、巫蛊血案与昭宣中兴（第 9–13 章）
*   **第五卷：日落西京与光武重光（前 48 — 公元 88）**：王莽改制、昆阳神迹、云台将星与班超定西域（第 14–18 章）
*   **第六卷：东京残照（公元 88 — 公元 220）**：外戚宦官死循环、党锢悲歌、董卓焚洛与汉室落幕（第 19–24 章）
